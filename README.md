# my-first-pr

A tiny demo project for practicing the full pull-request workflow with Claude Code.

## What's inside

- `greet.sh` — prints a friendly greeting (defaults to `World`).
- `test.sh` — checks the greeting output.

## Usage

```sh
./greet.sh Claude
# Hello, Claude!

./greet.sh
# Hello, World!
```

## Running the tests

```sh
./test.sh
```
